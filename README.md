## 🤖 My AI Stack (How I Work)
I use a multi‑agent ecosystem to augment my thinking and accelerate my work:

- **Microsoft Copilot**: ideation, writing, planning, conceptual modeling  
- **Claude**: scheduling, development assistance, GitHub Copilot support  
- **Firefly**: image generation, graphic design, creative assets  
- **Krisp**: meeting notes, lecture capture, training documentation  
- **Alexa+**: voice‑driven tutoring, spaced repetition, daily Q&A  

I treat AI tools like a distributed cognitive system. Each model has a role, and I orchestrate them the way a systems engineer orchestrates services.
